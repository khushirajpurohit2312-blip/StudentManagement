# Student Management System

## Project Description
This project is a simple Student Management System developed using HTML, CSS, and JavaScript. It demonstrates the use of Git and GitHub version control by implementing a standard branching workflow.

## Features
- Add Student
- Display Student Details
- Search Student by ID
- Delete Student Record

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub
